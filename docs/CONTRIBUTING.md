# المساهمة

## بيئة التطوير
```bash
npm install
npm run dev
```

## قبل الـ PR
- `npx tsc --noEmit` بدون أخطاء
- `npm test` كل الاختبارات تمر
- `npm run build` ينجح

## اصطلاحات الكود
- ملف واحد = مكون واحد (`.tsx`) أو أداة واحدة (`.ts`)
- أنواع الكيانات في `src/types/` فقط
- النصوص العربية مباشرة في الموديولات، والمفاتيح المشتركة في `src/i18n/`
- استخدام `useStore` للوصول للبيانات — لا `useState` للبيانات المشتركة
