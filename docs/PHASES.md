# خطة المراحل الأربع

## المرحلة 1 — الأساس (30 ملفاً)
إعداد المشروع، نظام التصميم (توكنز CSS + وضع ليلي)، طبقة الأنواع، محرك البيانات، الأدوات المالية، الراوتر، i18n، الهيكل العام.

## المرحلة 2 — الموديولات الأساسية (30 ملفاً)
UI Kit كامل، رسوم SVG، البيانات التجريبية، ثم: لوحة التحكم، نقطة البيع، المخازن، العملاء، الفواتير.

## المرحلة 3 — موديولات متقدمة (30 ملفاً)
CRM بخط بيع، HR وحضور، Kanban، محاسبة بقيود تلقائية، تقارير متعددة، تقويم شهري، إعدادات ونسخ احتياطي، مركز تنبيهات.

## المرحلة 4 — الجودة والتوثيق (30 ملفاً)
22 اختبار Vitest، ErrorBoundary، hooks إضافية، مكونات UI إضافية (Drawer, Avatar, Spinner, Progress...)، محددات أعمال (selectors)، حسابات مالية، توثيق كامل، قوالب Issues/PR، ترخيص MIT.
