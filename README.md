## ✨ نظرة عامة

نظام ERP مصغر بأفكار معمارية من **Odoo** و**ERPNext**: كل جزء من النظام موديول مستقل فوق طبقة بيانات واحدة، مع محاسبة تلقائية (كل فاتورة تسجل قيداً في دفتر اليومية)، وخصم/إضافة تلقائية للمخزون، وتنبيهات ذكية. كل هذا بدون أي مكتبة تشغيل خارج React — الرسوم البيانية مرسومة بـ SVG من الصفر.

## 🏗️ البنية

```
src/
├── components/     # نظام UI مصمم يدوياً + رسوم SVG بلا مكتبات
├── modules/        # 13 موديول أعمال منفصل
├── store/          # طبقة حالة مركزية + write-through فوري للسحابة
├── lib/backend.ts  # ربط Supabase: مصادقة، قراءة، كتابة موثقة + طابور إعادة محاولة
├── lib/            # أدوات مالية/تواريخ/CSV/طباعة/تحقق (مختبرة بـ Vitest)
├── i18n/           # عربي/إنجليزي مع RTL/LTR تلقائي
├── hooks/          # useDebounce, useLocalStorage, useKeyboard, useMediaQuery
├── router/         # راوتر hash مكتوب يدوياً — بدون react-router
└── seed/           # بيانات تجريبية واقعية
```

## 🎯 تحديات تقنية

- **TypeScript صارم** — أنواع كاملة لكل كيان في `src/types/`
- **اختبارات وحدة بـ Vitest** — 22 اختباراً للمحرك المالي والبيانات
- **محرك رسوم SVG من الصفر** — Bar / Line / Donut / Sparkline بدون Chart.js
- **دفتر يومية محاسبي** — كل فاتورة تُولّد قيداً تلقائياً
- **i18n كامل** — تبديل عربي/إنجليزي مع RTL/LTR فوري
- **وضع ليلي** — نظام توكنز CSS كامل
- **CI/CD** — GitHub Actions يبني وينشر تلقائياً على GitHub Pages

## 🚀 تشغيل محلي

```bash
git clone https://github.com/noooreldein/noor-suite.git
cd noor-suite
npm install
npm run dev      # تطوير
npm test         # اختبارات
npm run build    # بناء الإنتاج
```
